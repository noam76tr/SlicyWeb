# Filament Errors

Phase 8, ADR-033. FIL_003 to FIL_005: filaments entered by the user (Manage Filaments, lot 71).

## FIL_001

```text
Filament Not Found
```

A filament id that is not loaded (filament:update, filament:remove, or the last filament of the settings, which is then ignored).

## FIL_002

```text
Invalid Filament Profile
```

A filament file that cannot be read, is larger than the size limit (1 MB), fails the Repository Data Schema or Filament Schema validation (for a shipped filament: the four temperatures are required, color and pricePerKg are null), has a source other than the source of its folder, or whose id is already loaded. The file is refused; the other filaments are loaded (Phase 8 lot 68).

## FIL_003

```text
Filament Not Editable
```

filament:update or filament:remove on a filament that was not entered by the user (Official filament). Official filaments are never changed.

## FIL_004

```text
Filament Already Exists
```

filament:add or filament:update with the brand, the name and the color of another loaded filament (case and outer spaces ignored; no color matches no color).

## FIL_005

```text
Filament Not Saved
```

The file of a filament of the user could not be written or deleted (disk full, no right to write). Nothing is changed. The message gives the system error code, never a path.

# Analysis Errors

Phase 9, ADR-034. The analysis is computed in a Web Worker; its messages are translated and shown like the messages of the import (GUI_SPEC.md, Error Handling UI). In Phase 9, a failure of any part of the computation (volume, overhangs...) is reported as ANA_001; ANA_003 and ANA_004 are not used yet.

---



## ANA_001



```text

Analysis Failed

```

Severity: Error. The mesh of the object is empty or cannot be read, or the computation fails. No analysis is stored for the object (an outdated analysis stays outdated).

---



## ANA_002



```text

Mesh Validation Failed

```

Severity: Warning, non-blocking (ADR-034 D6). The mesh is not closed: an edge is shared by an odd number of triangles (1: a hole; 3: the surface is open somewhere too; 2.5.0, Noam 2026-11-08). The analysis is computed and stored anyway; message: "Mesh not closed: volume and wall thickness are approximate". No field of DATA_SCHEMA.md keeps it: it is found again at each computation.



---



## ANA_003



```text

Volume Calculation Failed

```



---



## ANA_004



```text

Overhang Analysis Failed

```



---



## ANA_005



```text

Mesh Not Manifold

```



Severity: Information, non-blocking (2.5.0, lot 91, Noam 2026-11-08). The mesh is closed (no edge with an odd number of triangles), but some edges are shared by 4, 6… triangles: parts touch along an edge. The volume and the wall thickness stay reliable. Message: "Non-manifold mesh: some parts touch along an edge", shown in the Analysis section only (grey, never over the viewport), as long as the last analysis of the object finds it; no reduction of the recommendation confidence; the feature holes is not computed (OBJECT_CLASSIFICATION_SPEC.md 1.2.2). Not shown when the mesh is not closed (ANA_002 already says that the analysis is approximate). No field of DATA_SCHEMA.md keeps it.

# Recommendation Errors

Phase 10, ADR-035. The recommendation is generated by rules in the window (no Web Worker). Its errors are shown in the Recommendation section only (GUI_SPEC.md, Recommendation Section), never over the viewport. The warnings of a recommendation are not error codes: RECOMMENDATION_RULES.md 1.1.0, Recommendation Warnings.

---



## REC_001



```text

Recommendation Failed

```

Severity: Error. Unexpected failure of the computation, or a recommendation refused by RecommendationSchema. No recommendation is stored for the object (an outdated recommendation stays outdated). Shown in the Recommendation section; Tools > Generate Recommendations tries again.



---



## REC_002



```text

Insufficient Data

```

Severity: Information, non-blocking (ADR-035 D11). No recommendation can be generated yet. Cases:

```text
No printer or no material selected: the section shows
  "Select a printer and a material"
The analysis of the object is missing or its classification is null
No Balanced preset available (PRINT_PRESETS_SPEC.md, Default Preset)
No fan value: a family without a value in RECOMMENDATION_RULES.md 1.1.0
  (Temperature And Cooling) and a filament without a published fan
```

No message over the viewport: the recommendation is generated by itself as soon as the missing data exist.



---



## REC_003



```text

Configuration Conflict

```

Not used in Phase 10 (ADR-035 D9): a conflict (object too large, temperature not supported) is a critical warning of the recommendation and does not block it; the export (Phase 14) decides what is blocked.

# Cache Errors



---



## CACHE_001



```text

Cache Corrupted

```



Printer profiles (Phase 7 lot 62): the cache of the profile repository (cache/printers/ of the user data folder) exists but fails its validation at start (cache.json, SHA-256, index.json or a profile file). It is not used: the profiles of the application (data/printers/) are loaded, the code is written to the log of the main process, and the next check rebuilds the cache.

# RepositorySync and Remote Source Errors

## SYNC_001
Repository Synchronization Failed

Printer profiles (Phase 7 lot 62): the download is valid but the cache cannot be written, or no synchronization is available; the profiles in use are kept.

## SYNC_002
Remote Source Unavailable

Printer profiles: network error, or an HTTP status other than 200 for index.json or a profile file; the profiles in use are kept. HTTP 404 (index.json or tag not published yet) is written to the last check with this code, but it is not shown as a failure: the repository is reachable, and Refresh Profiles says that no version is published yet.

## SYNC_003
Remote Source Timeout

Printer profiles: a file of the profile repository does not arrive within 15 seconds; the profiles in use are kept.

## SYNC_004
Remote Data Validation Failed

Printer profiles: index.json or a profile file is refused (address, size of a file or of the whole download, tag, SHA-256, UTF-8, JSON, Profile Repository Index Schema, Printer Schema, source or id); the whole download is refused and the profiles in use are kept.

## SYNC_005
Remote Data Conflict

## SYNC_006
RepositorySync Configuration Invalid

## SYNC_007
Remote Source Access Forbidden

# Logging Requirements

Every error must record:

```text
Timestamp

Code

Severity

Module

Message
```

Additional logging rules:

```text
Error codes must be unique.

Error messages must be safe for user display.

Sensitive information must never be written to user-visible logs.

Remote source URLs must be sanitized when logged.

Authentication tokens and credentials must never be logged.

IPC payloads must not be logged when they contain sensitive data.

RepositorySync failures must include the affected repository or source identifier when available.
```

---

# User Display Rules

Show:

```text
Friendly Message
Error Code
Recovery Action When Available
```

Do Not Show:

```text
Stack Traces
Internal Paths
Sensitive Information
Authentication Tokens
Credentials
Raw Remote Responses
Internal IPC Payloads
```

User-facing error messages must be localized through the internationalization system.

The user interface must not display raw internal exceptions.

Internal diagnostic details may be written to protected application logs when permitted by the security rules.

---



# Golden Rule



Every error must have a unique code.
