# Printer Errors



---



## PRN_001



```text

Printer Not Found

```



No loaded printer has this id (printer:get).



---



## PRN_002



```text

Invalid Printer Profile

```



Printer profile file refused at loading: larger than 1 MB, not readable, invalid JSON, not a valid Repository Data Schema envelope or printer (PrinterSchema), source other than the source of its folder, or id already loaded. The other files are loaded.



---



## PRN_003



```text

Unsupported Printer

```



---



## PRN_004



```text

Build Volume Invalid

```



---



## PRN_005



```text

Printer Not Editable

```



printer:update or printer:remove on a printer that was not entered by the user (Official printer). Official printers are never changed.



---



## PRN_006



```text

Printer Already Exists

```



printer:add or printer:update with the brand and the model of another loaded printer (case and outer spaces ignored).



---



## PRN_007



```text

Printer Not Saved

```



The file of a printer of the user could not be written or deleted (disk full, no right to write). Nothing is changed. The message gives the system error code, never a path.

# Logging Requirements

Every error must record:

```text
Timestamp

Code

Severity

Module

Message
```

Additional logging rules:

```text
Error codes must be unique.

Error messages must be safe for user display.

Sensitive information must never be written to user-visible logs.

Remote source URLs must be sanitized when logged.

Authentication tokens and credentials must never be logged.

IPC payloads must not be logged when they contain sensitive data.

RepositorySync failures must include the affected repository or source identifier when available.
```

---

# User Display Rules

Show:

```text
Friendly Message
Error Code
Recovery Action When Available
```

Do Not Show:

```text
Stack Traces
Internal Paths
Sensitive Information
Authentication Tokens
Credentials
Raw Remote Responses
Internal IPC Payloads
```

User-facing error messages must be localized through the internationalization system.

The user interface must not display raw internal exceptions.

Internal diagnostic details may be written to protected application logs when permitted by the security rules.

---



# Golden Rule



Every error must have a unique code.
