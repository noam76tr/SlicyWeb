# WICHY
# TERMINOLOGY

Version: 1.0.0

Status: Approved

---

# Purpose

This document defines the official terminology used throughout the Wichy project.

The objective is to ensure consistency across:

- Documentation
- User Interface
- Source Code
- APIs
- Data Models
- AI Recommendations

All contributors should use these terms whenever applicable.

---

# Terminology Rules

Use the official term whenever possible.

Avoid synonyms that could create confusion.

Example:

Correct:

```text
Printer Profile
```

Avoid:

```text
Printer Configuration
Printer Preset
Printer Settings File
```

unless a different meaning is intended.

---

## Model

Definition:

```text

```

---

## Mesh

Definition:

```text
Collection of vertices and triangles forming a 3D model.
```

---

## Build Plate

Definition:

```text
Virtual representation of the printer bed.
```

---

## Print Volume

Definition:

```text
Maximum printable volume supported by a printer.
```

---

## Layer

Definition:

```text
Single horizontal slice of a printed object.
```

---

## Layer Height

Definition:

```text
Thickness of an individual printed layer.
```

Unit:

```text
mm
```

---

## Nozzle

Definition:

```text
Printer component used to extrude material.
```

---

## Extruder

Definition:

```text
System responsible for feeding filament.
```

---

## Filament

Definition:

```text
Physical material used by FDM printers.
```

Definition:

```text
Generic category of printable material.
```

```text
ABS
```

Definition:


Definition:



Definition:


Definition:


---

## Thin Wall

Definition:

Definition:

Definition:

```text
Geometry extending beyond supported printable angles.
```

Definition:

```text
Probability that a model remains stable during printing.
```
